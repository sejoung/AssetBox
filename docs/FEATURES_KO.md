## 1. 개요

AssetBox는 게임 및 실시간 3D 콘텐츠 제작 파이프라인에서 3D 에셋의 품질을 빠르게 미리보기하고 검증하는 데스크톱 애플리케이션입니다.

- **프레임워크:** Tauri 2 (Rust 백엔드 + React 프론트엔드)
- **3D 렌더링:** Three.js + React Three Fiber
- **플랫폼:** Windows, macOS, Linux
- **기본 창 크기:** 1280 x 800px (최소 900 x 600px)

## 2. 지원 파일 포맷

### 3D 모델 입력

| 포맷 | 확장자 | 로더 |
|------|--------|------|
| FBX | `.fbx` | FBXLoader |
| glTF/GLB | `.glb`, `.gltf` | GLTFLoader |
| OBJ | `.obj` | OBJLoader |

### 텍스처 (자동 감지)

| 포맷 | 확장자 |
|------|--------|
| PNG | `.png` |
| JPEG | `.jpg`, `.jpeg` |
| TGA | `.tga` |
| TIFF | `.tiff`, `.tif` |
| BMP | `.bmp` |
| EXR | `.exr` |

### 출력

| 유형 | 파일명 패턴 | 설명 |
|------|-------------|------|
| 썸네일 | `{모델명.확장자}_thumbnail.png` | 뷰포트 스크린샷 |
| 검증 리포트 | `{모델명.확장자}_report.html` | HTML 상세 검증 보고서 |

## 3. 드래그 앤 드롭

두 가지 드래그 앤 드롭 시스템이 동시에 동작합니다:

### Tauri 네이티브 드롭
- `appWindow.onDragDropEvent()` API 사용
- 운영체제 네이티브 파일 드롭 이벤트 처리
- 지원 확장자만 필터링 (fbx, glb, gltf, obj)

### HTML5 드롭존
- 브라우저 표준 `onDragOver` / `onDrop` 이벤트 처리
- 드래그 시 시각적 피드백 (테두리 강조, 스케일 애니메이션)
- 파일이 없을 때 "Drag & Drop 3D File" 안내 표시

### 파일 경로 처리
- Windows 백슬래시 경로(`C:\Users\...`)를 Tauri asset 프로토콜 URL로 자동 변환
- 한글, 공백, 특수문자가 포함된 경로 지원
- 경로 세그먼트별 개별 인코딩으로 슬래시 보존

## 4. 뷰 모드

### 4.1 Solid (기본)
- 기본 머티리얼 렌더링
- 내장 텍스처가 있으면 표시
- 앱 내부에서 생성하는 스튜디오 환경 조명. 첫 미리보기는 외부 HDR 다운로드를 기다리지 않습니다.

### 4.2 Wireframe
- 메시의 엣지 구조를 표시
- 원래 머티리얼을 어두운 반투명으로 교체
- 초록색 와이어프레임 라인 오버레이
- 토폴로지 구조 확인에 유용

### 4.3 Normals

- 빨간 점은 면의 정점 순서와 정점 노멀이 불일치하는 삼각형의 정점입니다.
- 파란 점은 불일치로 표시되지 않은 정점입니다. 안팎 방향을 보증하지 않습니다.
- `Normal mismatches (N vertices)`를 누르면 표시된 정점의 중심으로 이동합니다.
- 검사 패널은 삼각형 수, 포커스 버튼은 정점 수를 표시합니다.

### 4.4 Normal Map (노말맵 뷰)
- 커스텀 셰이더로 버텍스 노말 방향을 RGB 색상으로 시각화
- X축 → R, Y축 → G, Z축 → B (범위 0~1 매핑)
- 전형적인 보라색/파란색 노말맵 렌더링

### 4.5 UV
- UV 체커 텍스처로 UV 펼침 상태를 시각화
- 빨간/남색 체크무늬 패턴 적용
- 그리드 라인 표시로 UV 왜곡 확인 가능
- UV 시임과 스트레칭 감지에 유용

### 4.6 Retopo (리토폴로지 진단)
- 삼각형 밀도 히트맵으로 메시 품질 시각화
- **색상 의미:**
  - 파란색: 과밀 영역 (평균 대비 삼각형이 너무 작음)
  - 초록색: 적정 밀도
  - 빨간색: 과소 영역 (삼각형이 너무 큼)
  - 노란색 계열: 얇은 삼각형 (aspect ratio 불량)
- **상단 진단 패널 표시:**
  - 리토폴로지 필요 여부 판정 (초록/빨간 표시등)
  - 총 삼각형 수
  - 얇은 삼각형 비율 (aspect ratio > 10이면 불량)
  - 과밀/과소 영역 비율
  - 밀도 편차 비율
  - 문제 사유 목록
  - 색상 범례

## 6. 검증 시스템

모델을 로드하면 Geometry, Topology, UV, Texture, Material, Scale / Transform을 검사합니다. [검사 가이드](VALIDATION_GUIDE.md)에 각 항목의 기준, 수정 방향과 측정 한계를 정리했습니다.

- **Checked:** 수행한 검사에서 문제 신호가 없음.
- **Review:** 참고 예산 초과나 용도에 따라 허용 가능한 구조. 의도와 목표 환경을 확인.
- **Needs attention:** 실패한 리소스, 필요한 UV 채널 누락, 높은 퇴화 면 비율 등 확인할 문제.
- **Incomplete:** 측정이나 원본 정보 확인이 불가능함. 정상 판정이 아님.

개별 보기와 일괄 검사는 같은 검사 경로를 사용합니다. 전체 상태는 Needs attention → Review → Incomplete → Checked 순으로 우선하며, 확인 불가 항목은 상세 패널·리포트에 남습니다.

### 검사 위치 확인

- 바닥 그리드는 기본으로 숨깁니다. 일반 보기에서는 `Grid`로 켤 수 있으며 검사 위치 강조 중에는 자동으로 숨깁니다. 강조를 해제하면 이전 설정으로 돌아갑니다.

- `Locate in model`을 클릭하면 해당 선·면·메시를 주황색으로 표시하고 카메라를 이동합니다.
- 상세 패널에서 대상별로 이동하고 메시 이름·개수·관련 재질과 텍스처 연결을 확인합니다.
- 실제 실패 경로만 확인 가능한 항목은 `Show resource details`로 표시하며 메시를 추정하지 않습니다.
- `Clear focus`·`Close details`·`Escape`로 강조를 해제합니다. 파일 변경 시 선택을 비우며 검수 이력을 저장하지 않습니다.
- 위치 표시 범위와 오버레이 제한은 [검사 가이드](VALIDATION_GUIDE.md)를 참고하세요.

## 7. 텍스처 자동 감지

### 지원 텍스처 유형

| 유형 | 매칭 키워드 |
|------|-------------|
| BaseColor | basecolor, diffuse, albedo, color, col, diff |
| Normal | normal, nrm, norm, nml |
| Roughness | roughness, rough, rgh |
| Metallic | metallic, metalness, metal, mtl |
| AO | ao, ambientocclusion, occlusion, occ |
| Emissive | emissive, emission, emit |
| Height | height, displacement, disp, bump |
| Opacity | opacity, alpha, transparency |

### 매칭 규칙
- 대소문자 무시
- 파일명 끝에서 구분자(`_`, `-`, `.`) 뒤의 키워드 매칭
- 패턴: `[_\-.]<type>$` (확장자 제외 파일명 끝부분)
- 인식된 이미지 확장자만 처리
- 주변 파일 발견에만 사용하며 필수 텍스처 누락을 추정하지 않음. 실제 실패한 리소스는 로더에서 별도 수집.

## 8. 내보내기 기능

### 썸네일 (Thumbnail)
- 현재 뷰포트를 PNG 스크린샷으로 저장
- 그리드는 캡처에서 자동 제외
- 원본 확장자를 포함해 모델 파일 옆에 `chair.glb_thumbnail.png`로 저장
- 상태 피드백: 대기 → 저장 중 → 완료/실패

### 검증 리포트 (Report)
- HTML 형식의 상세 검증 보고서 생성
- 원본 확장자를 포함해 모델 파일 옆에 `chair.glb_report.html`로 저장
- **포함 내용:**
  - 생성 타임스탬프 (한국어 로케일)
  - 파일 정보: 포맷, 파일명, 종합 판정
  - 카테고리별 검증 결과
  - 각 항목별 한국어 설명 및 기준치
  - 텍스처 파일 목록
  - 색상 코딩된 심각도 표시
  - 인쇄 친화적 스타일링

## 9. UI 구성

공통 색상·글자·간격·반응형 배치와 변경 기준은 [디자인 가이드](DESIGN_GUIDE.md)를 따릅니다.

| 영역 | 구성 |
| --- | --- |
| 앱 헤더 | AssetBox, 파일 탐색기 표시 전환, 폴더 열기 |
| 왼쪽 Files | 폴더 이동, 검색, 필터, 파일 목록, 일괄 검사 |
| 중앙 Preview | 현재 파일명, 3D 캔버스, 보기 모드 6종, 배경 3종, Fit model |
| 오른쪽 Asset information | 파일 요약과 등급, 리깅 정보, 카테고리별 검사, 텍스처, Report·Thumbnail·Logs |

파일 목록과 검사 정보는 각각 스크롤합니다. 보기 도구와 저장 버튼은 각 영역 안에 배치하며, 정보 패널을 접으면 모델을 볼 수 있는 공간이 넓어집니다. 파일을 바꿔 검사하는 동안 이전 파일의 상세 정보와 내보내기 버튼은 숨깁니다.

기본 창은 1280 × 800px, 최소 창은 900 × 600px입니다. 창 너비가 1100px 이하면 정보 패널 폭을 줄이고 보조 단축키 배지를 숨깁니다. Preview 영역이 570px 이하면 보기 모드는 3열 × 2행으로 표시합니다.

## 10. 백엔드 명령어 (Tauri)

### `scan_asset_directory`
- **입력:** 모델 파일 경로
- **기능:** 모델 파일이 위치한 디렉토리 스캔
- **출력:** 모델 메타데이터, 형제 파일 목록, 발견된 텍스처 파일 목록
- 이미지 확장자만 텍스처로 분류

### `save_thumbnail`
- **입력:** base64 PNG 데이터, 저장 경로
- **기능:** base64 디코딩 후 PNG 파일 저장
- 상위 디렉토리 자동 생성

### `save_text_file`
- **입력:** 텍스트 콘텐츠, 저장 경로
- **기능:** HTML 리포트 파일 저장
- 상위 디렉토리 자동 생성

## 리깅 정보

FBX·GLB·glTF의 본 계층·이름 검색, 스킨 연결과 최대 영향 수, 애니메이션 클립 이름·길이·트랙 수를 표시합니다. `Show bones`로 본을 모델 위에 겹쳐 볼 수 있습니다. 리깅 정보는 검사 등급에 반영하지 않습니다. 클립 재생과 IK·컨트롤 리그 검사는 지원하지 않습니다.

본을 목록이나 3D 화면에서 선택하면 직접 스킨 가중치 영역과 메시별 영향 정점 수를 확인할 수 있습니다. 가려진 본은 옅게 표시하며 표시 전환은 카메라를 이동시키지 않습니다.
