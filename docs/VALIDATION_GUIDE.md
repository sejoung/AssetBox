# 검사 결과 해석과 구현 기준

AssetBox는 로드된 모델에서 관찰한 사실을 보고합니다. 모델의 용도, 목표 기기, 의도한 재질을 자동으로 확정하지 않습니다. 색상은 납품 합격·불합격을 의미하지 않습니다.

## 상태

| 표시            | 의미                                                          | 다음 행동                                    |
| --------------- | ------------------------------------------------------------- | -------------------------------------------- |
| Checked         | 수행한 검사에서 표시할 문제가 없음                            | 목표 환경에서 최종 확인                      |
| Review          | 용도에 따라 허용 가능한 구조나 참고 예산 초과                 | 의도와 성능 예산을 확인하고 필요한 경우 개선 |
| Needs attention | 리소스 읽기 실패, 필요한 UV 채널 누락, 높은 비율의 퇴화 면 등 | 원인과 해당 부위를 확인                      |
| Incomplete      | 측정값이나 원본 재질 정보를 확인하지 못함                     | 원본 편집기·파일 접근 상태 확인 후 재검사    |

전체 상태 우선순위는 Needs attention → Review → Incomplete → Checked입니다. 확인 불가 항목은 경고가 함께 있어도 상세 패널과 리포트에 남습니다. `Needs review` 필터는 경고·문제·확인 불가 결과를 포함합니다. 아직 검사하지 않은 파일과 검사 실패로 확인 불가인 파일은 구분합니다.

상태 이름과 색은 [validationStatus.ts](../src/lib/validationStatus.ts)에 정의합니다. 내부 값은 각각 `good`, `warning`, `bad`, `unknown`입니다.

## 항목별 판단

| 항목                 | 현재 판정과 개선 방향                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Tris / Verts         | 각각 100,000 초과 시 Review. 목표 환경에 필요한 경우 LOD나 단순화 검토                                              |
| Meshes               | 50 초과 시 Review. 메시 수만으로 드로우콜이나 성능을 단정하지 않음                                                  |
| File Size            | 50 MiB 초과 시 Review. 읽기에 실패하면 Unknown으로 표시                                                             |
| Degenerate Tris      | 면적이 0이거나 수치상 붕괴한 면이 있으면 Review, 전체의 5% 초과면 Needs attention. 의도하지 않은 면을 원본에서 정리 |
| Non-manifold         | 한 메시 안에서 같은 위치의 정점을 대응시킨 뒤 3개 이상 면이 공유하는 변을 검토                                      |
| Open Edges           | 하나의 면에 속하는 경계 변. 개수가 많아도 Review이며 의도한 열린 표면이면 유지 가능                                 |
| Normal Consistency   | 면의 정점 순서로 계산한 노멀과 정점 노멀의 평균 방향을 비교. 불일치는 Review이며 안팎 판정이 아님                   |
| Unchecked Normals    | 노멀이 없거나 유효하지 않음, 퇴화 면 등으로 비교할 수 없는 삼각형 수                                                |
| No UVs               | UV 채널 없는 메시를 Review로 안내. 단색·생성 좌표 재질에는 UV가 불필요할 수 있음                                    |
| Missing Required UVs | 로드된 재질의 UV 매핑 텍스처가 참조하는 채널이 실제 메시에 없으면 Needs attention                                   |
| Bound Textures       | 로드된 재질의 고유 텍스처 개수. 공유 텍스처는 한 번만 집계                                                          |
| Max Resolution       | 읽을 수 있는 실제 텍스처 이미지 크기의 최댓값. 4096px 초과는 Review. 일부만 측정되면 partial과 Incomplete 안내      |
| Failed Resources     | 로더가 실제로 읽기에 실패한 리소스. 경로·권한·원본 연결 상태 확인                                                   |
| Source Materials     | OBJ의 MTL 파일은 현재 로더가 읽지 않으므로 Not checked. 기본 재질을 원본 재질 검증 성공으로 간주하지 않음           |
| Non-uniform Scale    | 의도한 비균일 스케일인지 검토. 리깅이나 변환 요구사항을 확인한 뒤 수정                                              |
| Center Offset        | 바운딩 박스 중심에서 씬 원점까지의 거리. 10 모델 단위 초과는 Review. 피벗 오류를 의미하지 않음                      |

참고 예산과 같은 값은 Checked이며 **초과**할 때 Review입니다. 예산 기준은 현재 공통값이며 기기별 프리셋은 구현되어 있지 않습니다.

## 검사 위치 확인

정보 패널에서 `Locate in model`이 있는 검사 항목을 클릭하면 해당 위치로 카메라가 이동합니다. 선택한 대상은 주황색으로 표시하며, 가려진 면 뒤에서도 보이도록 표시합니다. 주황색은 선택 위치를 뜻하며 새로운 심각도 등급이 아닙니다.

| 항목                                   | 표시되는 근거                                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Open Edges / Non-manifold              | 해당 경계 변 / 3개 이상 면이 공유하는 변                                                                        |
| Degenerate Tris                        | 해당 삼각형의 선과 정점. 면적이 없는 면도 정점으로 확인 가능                                                    |
| Normal Consistency / Unchecked Normals | 불일치 / 검사 불가 삼각형. 기존 Normals 보기의 정점 표시와 구분                                                 |
| No UVs / Missing Required UVs          | 해당 메시와 범위. 필요한 UV가 없으면 재질·맵 슬롯·요구 채널 표시                                                |
| No Material / Non-uniform Scale        | 해당 메시 / 변환이 설정된 오브젝트와 범위                                                                       |
| Bound Textures / Max Resolution        | 연결된 메시·재질·맵 슬롯·UV 채널·측정 크기. 해상도 예산 경고는 초과한 연결만 표시                               |
| Failed Resources                       | `Show resource details`로 실제 실패 경로 표시. 소유 메시·재질은 로더가 알려주지 않으므로 추정해서 강조하지 않음 |

- 상세 패널의 이전·다음 버튼과 `Affected object` 선택으로 해당 오브젝트를 하나씩 확인합니다. 검사 행은 모델 전체 수, 상세 정보는 선택한 오브젝트의 수를 표시합니다.
- 초점 확인 중에는 Solid 위에 위치를 표시합니다. `Clear focus`, `Close details`, `Escape`는 강조를 해제하고 이전 보기 모드로 돌아갑니다. 다른 보기 모드를 선택하면 강조를 해제하고 그 모드로 이동합니다. `Fit model`은 강조를 유지한 채 모델 전체를 보여줍니다.
- 파일을 바꾸거나 로드에 실패하면 이전 선택을 비웁니다. 선택·상세 정보를 파일이나 검수 이력으로 저장하지 않습니다. 기존 Thumbnail은 현재 화면을 캡처하므로 강조 없는 이미지가 필요하면 먼저 강조를 해제합니다.
- Tris·Verts 같은 모델 전체 참고 예산이나 측정 불가 값에는 임의의 문제 위치를 만들지 않습니다.
- 토폴로지 판정은 원본 기본 형상을 사용합니다. 위치 표시는 중첩 변환과 로드된 스킨·모프 포즈를 반영하며 애니메이션 시간별 재검사는 하지 않습니다. 인스턴스는 공유 형상의 검사 수와 전체 인스턴스 범위만 표시하고, 개별 면을 강조하지 못함을 안내합니다.
- 한 선택에서 선·삼각형 오버레이는 총 20,000개까지 유지합니다. 수와 초점 범위는 전체 결과를 반영하며, 표시가 제한되면 상세 정보에 알립니다. 오버레이를 배정하지 못한 대상은 범위 상자로 표시합니다. 유효하지 않은 좌표는 그리지 않습니다.

## 측정 범위와 한계

- **정점 분리:** UV·노멀 경계에서 같은 위치에 복제된 정점은 검사상 같은 점으로 취급합니다. 렌더링용 정점, UV, 노멀은 변경하지 않습니다.
- **변 연결:** 정확히 같은 위치만 대응시키며 작은 틈을 임의 허용 오차로 합치지 않습니다. 각 메시 내부만 검사하므로 겹친 별도 셸이나 메시 간 연결의 의도를 판단하지 못합니다. 경계가 없다는 결과는 닫힌 체적·3D 프린팅 적합성의 증명이 아닙니다.
- **노멀:** 전체 면과 노멀이 함께 안쪽을 향하면 일관성 검사는 통과할 수 있습니다. 화면의 빨간 점은 불일치 삼각형에 속한 정점이며, 포커스 버튼은 정점 수, 검사 패널은 삼각형 수를 표시합니다. 파란 점도 원본 방향이 올바르다는 보증은 아닙니다.
- **크기:** 퇴화 면 판정은 변을 정규화한 뒤 수행해 작은 모델을 면적 절대 기준으로 오판하지 않도록 합니다.
- **UV:** `uv`, `uv1`, `uv2` 등 실제 채널을 읽고 텍스처가 요구하는 채널과 대조합니다. 겹침·왜곡·유효한 언랩 여부까지 검증하지 않습니다.
- **텍스처:** 이미지 로딩이 끝난 뒤 측정하며 2048 같은 추정값을 사용하지 않습니다. 읽을 수 없는 이미지, 실패한 리소스, 미지원 재질 참조는 확인 불가로 남깁니다. 측정한 텍스처가 없고 재질 참조 검사가 완료된 경우만 Not used로 표시합니다.
- **주변 파일:** Nearby texture files는 이름 패턴으로 발견한 주변 파일 목록입니다. 해당 모델이 사용하거나 반드시 필요로 하는 파일 목록이 아닙니다. basecolor·normal·roughness를 일괄 필수로 가정하지 않습니다.
- **Retopo:** 삼각형 분포의 참고 신호입니다. `No density flags`는 다른 토폴로지 항목의 통과를 의미하지 않으며, `Review triangle distribution`도 리토폴로지를 강제하지 않습니다.

## 리깅 정보

FBX·GLB·glTF를 읽으면 `Rigging`에 본 계층과 스킨 연결, 애니메이션 클립 메타데이터를 표시합니다. 공유 본은 고유 오브젝트 기준으로 한 번 세고, 스킨 수는 로더가 만든 고유 Skeleton 수입니다. 본만 있는 파일과 스킨 메시가 있는 파일을 구분합니다. OBJ는 본·스킨·클립을 저장하지 않습니다.

`Skin bindings`의 최대 영향 수는 정점에 양의 가중치로 연결된 유효한 고유 본 수입니다. 유효한 가중치가 없는 정점과 잘못된 영향 정보가 있는 정점도 표시합니다. 속성이 없거나 길이가 맞지 않으면 `Not checked`로 남깁니다. 이 수치는 로더가 보존한 데이터 기준입니다. FBX 등의 로딩 중 영향 수 제한이나 가중치 정규화가 적용될 수 있으므로 원본 편집기의 값과 항상 같다고 보장하지 않습니다. 리깅 정보는 전체 검사 등급에 반영하지 않습니다.

`Show bones`로 로드된 포즈의 관절·연결선을 볼 수 있습니다. 본 검색은 대소문자를 구분하지 않습니다. 애니메이션은 이름·길이·트랙 수만 표시하며 재생·시간별 변형 검사는 지원하지 않습니다. Blender의 컨트롤 리그, IK 제약, 드라이버의 원래 의미는 검사하지 않습니다.

## 파일 변경과 재검사

- 현재 탐색 폴더 아래에서 원본·버퍼·텍스처 등의 변경을 감지하면 300ms 동안 묶어 처리하고, 현재 모델을 다시 읽습니다. 보기 모드와 배경 설정은 유지합니다.
- 파일 간 공유 리소스를 놓치지 않도록 변경 시 메모리에 있는 검사 등급과 미리 읽은 모델 캐시를 비우고 진행 중인 일괄 검사를 취소합니다. 이전 요청이 늦게 끝나도 그 결과를 다시 표시하지 않습니다.
- `Refresh` 또는 현재 모델 재선택으로 수동 재검사할 수 있습니다. 자동 감지 범위는 탐색 중인 폴더와 하위 폴더입니다. 그 밖의 참조 파일을 편집했거나 감지가 동작하지 않으면 `Refresh`를 사용합니다.
- 생성된 `_thumbnail.png`·`_report.html`만 변경된 경우 목록을 갱신하고 모델은 다시 읽지 않습니다. 출력 이름에는 원본 확장자를 포함해 `chair.fbx_thumbnail.png`와 `chair.glb_thumbnail.png`를 구분합니다. 예전 썸네일은 같은 이름의 다른 모델 형식이 없을 때만 연결합니다.
- Retopo 색은 임시 지오메트리에 적용합니다. 원본 정점 색·재질은 보존하며, 파일 교체나 뷰어 종료 시 원본 GPU 자원과 임시 표시 자원을 각각 해제합니다.

## 코드와 검증

- [geometryDiagnostics.ts](../src/lib/geometryDiagnostics.ts): 변 연결·퇴화 면·노멀 일관성·UV 채널
- [issueInspection.ts](../src/lib/issueInspection.ts): 원본 참조와 로드 포즈 보존, 선택 항목의 위치·연결 정보
- [IssueHighlight.tsx](../src/components/IssueHighlight.tsx): 원본을 변경하지 않는 위치 표시와 카메라 이동
- [IssueDetails.tsx](../src/components/IssueDetails.tsx): 오브젝트 이동, 근거·표시 제한 안내
- [materialInspection.ts](../src/lib/materialInspection.ts): 실제 연결 텍스처와 측정 가능 여부
- [modelResources.ts](../src/lib/modelResources.ts): 네이티브 경로 인코딩 전 외부 리소스의 상대 경로 해석
- [disposeScene.ts](../src/lib/disposeScene.ts): 원본 자원 추적과 중복 없는 해제
- [ModelLoader.ts](../src/components/ModelLoader.ts): 의존 리소스 로딩 완료 후 분석, 실패 리소스 수집
- [TextureMatcher.ts](../src/components/TextureMatcher.ts): 주변 파일 발견, 모델 파일 크기 읽기
- [useAssetValidation.ts](../src/hooks/useAssetValidation.ts): 판정·원인·개선 안내
- [assetPipeline.ts](../src/lib/assetPipeline.ts): 개별 보기와 일괄 검사에서 공유하는 검사 경로

로직 변경 시 닫힌 박스의 분리 정점, 열린 평면, 작은 의도적 틈, 서로 다른 모델 크기, 누락·반대 노멀, UV 채널 연결, 지연된 이미지 로딩, 부분 해상도 측정과 리소스 실패를 검증합니다. 판정 이름을 바꾸면 화면·파일 목록·리포트·이 문서를 함께 갱신합니다.
